## 模型选型记录：对话摘要提取（关键信息抽取）

### 结论

摘要/关键信息提取任务锁定 **Qwen3-0.6B-BF16**，不升级至 Qwen3.5-0.8B 或更大模型。

### 选型依据

| 对比项 | Qwen3-0.6B | Qwen3.5-0.8B |
|--------|-----------|--------------|
| 摘要准确率 | 优 | 差（明显不如 0.6B） |
| 推理速度 | 快 | 慢（约慢 60%+） |
| 输出格式稳定性 | 好 | 一般 |
| 资源占用 | 低 | 高 |

实验结论：在短文本关键信息提取场景下，更大参数量并未带来效果提升，反而因"过度思考"导致输出冗余、格式漂移，且延迟显著增加。0.6B 是该任务的最优甜点尺寸。

### 部署配置

- **模型文件**：Qwen3-0.6B-BF16.gguf
- **推理引擎**：llama.cpp server（版本锁定，禁止 latest）
- **量化精度**：BF16 原版权重直转，无精度损失

### Prompt

```
你是文本关键信息提取助手，从文本中复制出最关键的 10 个句子。规则：1.每个句子之间语义不重复；2.逐字复制原文，不改写、不总结；3.不输出引用位置、不添加任何解释；4.如果原文关键信息少于 10 个句子，只输出关键信息，禁止编造。5.输出内容不需要编号，直接合并为一段话。
```

### 推理参数

| 参数 | 值 | 说明 |
|------|-----|------|
| --repeat-penalty | 1.05 | 抑制重复生成 |
| --min-p | 0.03 | 过滤低概率 token |
| --temperature | 0.1 | 低温，保证输出确定性 |
| --reasoning | off | 关闭思考链，直接输出结果 |
| --predict | 1024 | 最大生成长度 |

### 约束

- 提示词固定后作为基础设施，**不允许热更新**
- GGUF 文件需归档备案，更换版本前需回归测试
- llama-server 版本锁定，升级需评估 minja 解析兼容性
